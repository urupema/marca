# Marca do Instituto Urupema

Guia da marca: https://urupema.github.io/marca/ (fonte em [`docs/`](docs/), publicada pelo GitHub Pages a partir da `main`).

| Pasta | O que tem |
|---|---|
| `docs/` | O guia (`index.html`, `livro.css`) e tudo que ele serve para baixar |
| `docs/logo/` | Masters em SVG, texto em contorno. Ajuste no próprio SVG |
| `docs/modelos/` | Modelos editáveis em HTML; os impressos saem no formato certo pelo navegador |
| `docs/cores/` | Variáveis de cor para CSS e JSON |
| `contrato/brand-spec.json` | Decisões em vigor, para quem opera a marca. Muda junto com o guia |
| `referencias/` | Briefing de origem |

As fotos em `docs/fotografia/` são provisórias. Para trocar, substitua o arquivo mantendo o nome.
