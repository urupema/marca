# Marca do Instituto Urupema

O livro da marca é [`docs/index.html`](docs/index.html), publicado pelo GitHub Pages em https://urupema.github.io/marca/ — regras, masters, cores, fontes e modelos, na pasta `docs/`.

- `docs/index.html` e `docs/livro.css` — o livro, em HTML e CSS editados à mão.
- `docs/logo/` — os masters, finais: SVG com as letras em contorno, sem depender de fonte. Um ajuste se faz no próprio SVG.
- `docs/cores/` — as variáveis de cor para CSS e JSON; os modelos em `docs/modelos/` usam as mesmas.
- `docs/aplicacoes/` — capturas dos modelos em uso, que o livro mostra.
- `contrato/brand-spec.json` — decisões em vigor, em inglês, para quem opera a marca; nomes próprios (Palha, Tinta, Urucum, Forja…) e as frases da marca ficam como são. Muda junto com o livro.
- `referencias/briefing-mestre.docx` — o mandato desta etapa.

## Fotos provisórias

`docs/fotografia/provisoria-*.jpg` são provisórias, até existir acervo real. Para trocar, substitua o arquivo mantendo o nome: o livro e os modelos passam a mostrar a foto nova. As capturas em `docs/aplicacoes/` que contêm foto (`site-home.jpg`, `site-celular.jpg`, `formacao-celular.jpg`) precisam ser refeitas a partir do modelo aberto no navegador.
